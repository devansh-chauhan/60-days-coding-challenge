# Best Project Showcase

## Smart Spam Detector

An end-to-end Machine Learning application that classifies SMS messages as **Spam** or **Ham**.

### Features

- SMS data preprocessing
- Text vectorization using CountVectorizer
- Multinomial Naive Bayes classifier
- Interactive Streamlit interface
- Prediction confidence scores
- Performance optimization

### Technologies Used

- Python
- Pandas
- Scikit-learn
- NLTK
- Streamlit
