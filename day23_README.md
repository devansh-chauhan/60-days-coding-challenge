# Day 23 - Train Carriage Reversal Challenge

## Problem Statement

A railway company accidentally connected train carriages in the wrong order.

The goal is to reverse the train safely using linked list operations.

---

# Objectives

- Build a linked list representation
- Reverse the linked list
- Print original and reversed order
- Understand pointer manipulation
