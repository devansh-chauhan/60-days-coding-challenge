# Day 21 - Forbidden Functions Tournament

## Challenge Overview

This challenge focused on solving problems without using built-in helper functions such as:
- sort()
- sum()
- max()
- min()

The goal was to strengthen low-level problem-solving and algorithmic thinking.

---

# Problems Solved

## 1. Recursion Problem
Implemented factorial calculation using recursion.

### Concepts Practiced
- Recursive thinking
- Base case handling
- Function call stack

---

## 2. Stack Problem
Reversed a string using a manually implemented stack approach.

### Concepts Practiced
- Stack operations
- LIFO behavior
- Manual data manipulation

---

# Key Learnings

- Built-in functions hide important internal logic.
- Writing logic manually improves debugging ability.
- Understanding low-level operations builds stronger engineering intuition.

---

# Biggest Realization

Efficient engineers understand how systems work internally instead of relying entirely on helper functions.

---

# Challenges Faced

- Managing logic manually increased implementation complexity.
- Required deeper understanding of recursion and stack behavior.
- Small mistakes became easier to notice during debugging.

---

# Real-World Impact

Low-level problem-solving skills are useful in:
- System design
- Debugging complex applications
- Performance optimization
- Embedded systems
- Compiler development

---

# Conclusion

This challenge reinforced the importance of understanding core algorithms and data structure behavior without depending heavily on abstractions.
